## Summary

This document provides a template for creating LRS data products focused on asset counts. It guides users through selecting route networks, adding summary fields, choosing layers and fields for data summarization, and saving the template. The template includes roadway data and mileage statistics for county routes, covering attributes such as lanes, shoulders, pavement type, speed limits, and route milepost locations.
