## Slide 2 — User Story

As an GIS Administrator, I need the ability to quickly deploy LRS applications from templates in Experience Builder, so that I don’t have to spend hours configuring applications for unique users/groups in my organization.

Persona
GIS Administrator: This user is responsible for among other things, configuring and deploying applications for LRS users in the web.  At many organizations they will be deploying more than one generic LRS application and having a template to start with will make the deployment of these multiple applications much easier and faster.

## Slide 3 — LRS Templates in Experience Builder

Update the LRS templates in Experience Builder
Create visually appealing, well-organized templates for the LRS Viewer and LRS Event Editor templates
For the LRS Viewer template, include the following widgets: LRS Identify, LRS Route Search, LRS Dynamic Segmentation, Branch Versioning Management (the new one), Time (the new/updated widget)
For the LRS Event Editor template, include the following widgets: LRS Identify, LRS Route Search, LRS Add Point Event, LRS Add Line Event, LRS Split Event, LRS Merge Events, LRS Dynamic Segmentation, Branch Versioning Management (the new one), Time (the new/updated widget)
Review the templates with the team then work with Eric or Sharon to get them updated in Experience Builder
